# Research benchmark data notice

This directory contains project-selected subsets derived from the public development data of:

- **Spider 1.0** — [benchmark site](https://yale-lily.github.io/spider/) — distributed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
- **BIRD** — [benchmark site](https://bird-bench.github.io/) — distributed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).

QuickInsight preserves the selected public questions, source identifiers, gold SQL, BIRD evidence where supplied, and the source table values needed to execute those cases. It adds a deterministic selection manifest, browser-oriented JSON packaging, semantic column metadata, and DuckDB-WASM-verified frozen outputs.

The subsets are provided under the same CC BY-SA 4.0 terms. They are not complete benchmark splits and are not official leaderboard submissions. See `manifest.json` for the selection rule, constraints, source archive checksums, and exact case identities.
