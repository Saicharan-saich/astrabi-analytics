The problem

Most small and mid-sized businesses generate real operational data and have nobody whose job is to analyse it. A salaried analyst is out of proportion to the problem. Existing BI tools don't fix that — they move it: somebody still has to connect the data, define how tables relate and build a model before the first chart appears. That is analyst work, and buying the software does not supply the analyst.

The week before

  • Export the file, clean the dates and categories by hand
  • Rebuild the pivot table every time somebody asks
  • One person understands it — reporting stops when they're away
  • Questions nobody anticipated go into a queue, or go unasked

The week after

  • Drop the same file in; cleaning and profiling are automatic
  • Assemble a question from four choices, or type it in English
  • Anyone on the team can answer a routine question themselves
  • Repeat answers become a dashboard that never needs rebuilding

What it does

1
Automatic data cleaning A seven-layer pipeline standardises dates, separates numbers that can be summed from those that can't, reconciles categories spelled two ways, and profiles every column.
2
Question Builder — the GAFS method Every business question is four choices: Group by what, Aggregate which number, Filter which rows, Sort in what order. Learn that once and the questions stop being a fixed list.
3
Ask in plain English Type the question as you'd say it. The generated SQL stays visible and is checked against your real column names and values before it runs.
4
Automatic insights On load, QuickInsight surfaces what changed, what's concentrated in one product or region, and what looks wrong — before you've asked anything.
5
Dashboards and monitoring Pin the answers you need repeatedly. They refresh against the current file rather than being rebuilt by hand each period.
6
Multi-sheet joins, safely Related sheets are detected and joined automatically — and any join that would duplicate rows and inflate your totals is refused rather than silently applied.

The analytical database runs inside the browser tab, so the file itself is never uploaded — cleaning, queries and charts are all computed on the user's own machine. The server exists to hold accounts and to keep the model provider's API key off the client.

Privacy by architecture, not by policy

The file never leavesAnalysis happens in the browser. There is no upload step to opt out of, and nothing to delete afterwards.
Structure, not contentPlain-English questions send column names and types only. Sending sample values is off unless switched on.
Chosen column by columnIf values are shared, identifiers and personal data are excluded automatically, and every remaining column and value can be switched off individually.
